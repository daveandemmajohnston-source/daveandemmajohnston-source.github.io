Privacy Policy

Last updated: November 15, 2026

Johnston Home Automation is a private Home Assistant installation used only by the owner's household. It is not offered to the public.

What data it accesses

With the owner's permission, it connects to the owner's own Google account to (1) save Home Assistant backups to the owner's Google Drive and (2) read and control the owner's own Google Nest thermostat.

How the data is used

This data is used only to run the owner's home. It is kept on the owner's own Home Assistant server and Google Drive. It is not sold, shared with or disclosed to anyone else, and is not used for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
